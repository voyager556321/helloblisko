Нових волонтерів додаток не шукає. Вони вже є в списку філії: прізвище, телефон, район.

Ланцюжок:

1. Удома одна дія: людина затискає кнопку в PWA і каже вголос, що треба.
2. Запис іде координатору філії. Волонтери його не чують.
3. Координатор підтверджує один рядок («аптека, завтра о 10») і обирає одну людину зі свого списку.
4. Їй відкриваються адреса, 4 цифри і PESEL. Код у текст для решти не потрапляє.
5. Після аптеки вона ставить «видано». Цифри зникають з екрана.
6. Та сама кнопка скасовує відкритий запит.

Людину в список додає центр. Поки її там немає, запит їй не приходить.
